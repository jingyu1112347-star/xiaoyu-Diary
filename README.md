# 小幽日记 (XiaoYou Diary)

一款基于手机内置传感器的**人体行为实时识别**与**行为日记** Android 应用。它把手机变成一个随身携带的运动姿态观测器：实时读取加速度计与陀螺仪数据，在本地识别你当前的行为（行走、静坐、平躺等），给出置信度与姿态参数，自动汇总每天的行为分布，并可与日记、心情关联记录。

所有计算在本地完成，无需联网，无后端服务。

---

## 1. 项目解决什么问题

- **行为量化难**：日常活动量、久坐时长、运动状态难以自动、连续地记录。小幽日记用手机传感器做 24 小时可连续的行为采样，给出可回看的行为数据。
- **姿态不可见**：手机如何摆放、身体姿态如何，只能凭感觉。应用实时解算俯仰角 / 横滚角 / 偏航角（pitch / roll / yaw），让姿态可视化。
- **传感器零偏不准**：不同设备传感器存在零偏，直接使用会导致姿态漂移。应用提供一键**传感器校准**，记录零偏并在分析时扣除。
- **重复记录成本高**：自动按行为类型汇总分布、统计时长与切换次数，并可一键写入当天日记，省去手动整理。
- **久坐提醒**：支持久坐提醒、震动反馈、后台持续监测，提醒你适时活动。

## 2. 主要功能

### 2.1 行为实时识别（首页）
- 读取 3 个传感器：`TYPE_ACCELEROMETER`（加速度，含重力分离）、`TYPE_GYROSCOPE`（陀螺仪）、`TYPE_GRAVITY`（重力向量），默认 **50Hz** 采样。
- 实时识别 8 类行为：🚶 行走、🏃 慢跑、⚡ 快跑、🪑 静坐、🧍 站立、📱 倾斜、🛏️ 平躺、😴 侧躺。
- 首页实时展示：
  - 当前行为 + 置信度（%）；
  - 运行状态（检测中 / 已停止）与累计运行时长；
  - 实时姿态参数：俯仰角 / 横滚角 / 偏航角；
  - 8 类行为的概率排名列表。
- 操作：**开始检测 / 停止检测**、**单次检测**（弹出一次性结果）、**传感器校准**。

### 2.2 传感器校准
- 进入校准页后将手机水平静置，应用采样零偏并持久化保存；之后分析层会扣除该零偏，改善姿态解算。

### 2.3 数据分析
- 按周展示：总时长、检测次数、主要行为、达标率；
- 行为结构环形图、24 小时分布柱状图、周趋势折线图。

### 2.4 监测（日记）
- 当天行为摘要（行走 / 静坐 / 站立时长）；
- 心情选择、写日记；行为标签可随日记一起保存。

### 2.5 历史记录
- 按「今天 / 更早」列出历次检测会话：起止时间、主导行为、切换次数、总时长、分段明细。

### 2.6 设置
- **检测灵敏度**、**采样率**、**识别阈值**、**提醒间隔**（点击循环切换档位）；
- 开关：**久坐提醒**、**震动反馈**、**后台持续监测**、**深色模式**；
- 再次进入**传感器校准**。

### 2.7 UI 与交互
- Jetpack Compose + Material 3；液态玻璃风格（底部导航、卡片、按钮，深浅模式一致）；
- 底部 Tab 栏支持**左右滑动切页**、液态胶囊选中框、弹簧弹性动画；
- 数据全部本地存储（Gson 序列化到应用私有目录），包括设置、日记、行为记录。

### 2.8 权限
- `VIBRATE`（震动反馈）；
- `HIGH_SAMPLING_RATE_SENSORS`（Android 12+ 高频采样需要；未授予时自动降级，不会闪退）。
- 无需联网、无需定位、无需相机、无需通讯录等敏感权限。

## 3. 安装方法

### 3.1 环境要求
| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows / macOS / Linux 均可 |
| JDK | 17 或更高（项目 `sourceCompatibility` / `jvmTarget` = 17） |
| Android SDK | `compileSdk` 34，已安装 Platform API 34 与 Build-Tools |
| Android Gradle Plugin | 随项目 `gradle-wrapper` 自动下载（无需手动安装） |
| 运行设备 | Android 7.0（API 24）及以上，支持加速度计与陀螺仪 |

### 3.2 用 Android Studio
1. 打开 Android Studio → `Open` → 选择本项目根目录 `xiao/`。
2. 等待 Gradle 同步完成（首次会下载依赖）。
3. 连接手机（开启 USB 调试）或启动模拟器。
4. 点击 ▶ 运行，或菜单 `Build > Build Bundle(s) / APK(s) > Build APK(s)`。

### 3.3 用命令行（Windows PowerShell）
```powershell
# 1) 进入项目根目录（替换为你本地的实际路径）
cd <项目所在路径>\xiao

# 2) （如系统 JDK 不是 17，可临时指定，例如用 Gradle 下载的 JDK 21）
$env:JAVA_HOME = "C:\Program Files\Java\jdk-17"
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"

# 3) 编译 Debug 包
.\gradlew.bat assembleDebug

# 4) 产物路径
# app\build\outputs\apk\debug\app-debug.apk
```

### 3.4 安装到设备
```powershell
# 查看已连接设备
adb devices

# 安装 / 覆盖安装
adb install -r app\build\outputs\apk\debug\app-debug.apk
```
或直接把 `app-debug.apk` 拷到手机点开安装（需允许安装未知来源）。

## 4. 使用方法

1. **进入应用**：启动后点击启动页任意位置进入。
2. **开始检测**：首页点击「开始检测」，顶部显示当前行为、置信度与运行时长；姿态参数与行为概率实时刷新。
3. **停止 / 单次**：再点「停止检测」结束本次会话；「单次检测」立即给出一次识别结果。
4. **校准（首次建议）**：点「传感器校准」→ 手机水平静置 → 完成后返回，零偏自动保存。
5. **浏览数据**：底部 Tab 左右滑动或点击切换：
   - **分析**：本周行为统计与图表；
   - **监测**：当天摘要、写日记、记心情；
   - **历史**：历次会话；
   - **设置**：灵敏度、采样率、提醒、深色模式等。
6. **提醒**：开启「久坐提醒 + 震动反馈」后，到达提醒间隔会本地提醒；开启「后台持续监测」可在退到后台时继续采样（受系统后台限制约束）。

## 5. 输入输出示例

### 5.1 传感器输入 → 行为识别输出
输入（`SensorCollector` 每帧采集，约 50Hz）：
```text
加速度 (m/s²):  [0.2, 9.7, 1.1]     # 含重力
用户加速度:     [0.05, -0.1, 0.08]  # 去重力后
陀螺仪 (rad/s): [0.01, 0.00, -0.02]
重力向量:       [0.15, 9.78, 0.95]
```
经 `BehaviorAnalyzer` 阈值/规则判别后，UI 实时输出：
```text
当前行为: 行走 🚶
置信度:   92.4 %
姿态:     俯仰 -12.4°  横滚 3.8°  偏航 87.2°
概率榜:   行走 92.4% | 静坐 2.5% | 平躺 2.4% | 倾斜 2.3% | 侧躺 2.2% | ...
```

### 5.2 单次检测输入输出
- 输入：点击「单次检测」，应用取当前一帧传感器快照。
- 输出（Toast 提示示例）：`已启动单次检测`，随后弹出该次的行为与置信度。

### 5.3 校准输入输出
- 输入：进入校准页，手机水平静置数秒。
- 输出：`校准完成 · 传感器零偏已更新`，零偏持久化到本地设置；之后姿态参数会扣除零偏。

### 5.4 设置档位循环示例
- **采样率**点击循环：`25Hz → 50Hz → 100Hz → 200Hz → 25Hz`（实际受设备与权限约束，`hzToDelay` 封顶约 50Hz 档位，未授权高频采样时自动降级，不会闪退）。
- **检测灵敏度**点击循环：`25 → 50 → 68 → 85 → 100 → 25`。
- **识别阈值**点击循环：`0.50 → 0.60 → 0.65 → 0.70 → 0.75 → 0.80 → 0.85 → 0.90 → 0.50`。
- 「久坐提醒间隔」点击循环切换分钟档位，到点触发提醒。

## 项目结构（关键目录）
```
app/src/main/java/com/xiaoyou/diary/
├── MainActivity.kt              # 入口；Tab 页 Pager、液态玻璃模糊源
├── data/
│   ├── sensor/SensorCollector.kt     # 加速度/陀螺仪/重力 采集
│   ├── analyzer/BehaviorAnalyzer.kt  # 行为判别
│   ├── repository/BehaviorRepository.kt
│   └── storage/                      # 设置/日记/行为记录本地存储
├── model/Models.kt              # 8 类行为、概率、姿态、日记等数据模型
├── viewmodel/                   # Home / Analyze / Diary / Settings / App
├── ui/
│   ├── screens/                 # 首页、分析、监测、历史、设置、校准、启动页
│   ├── components/              # TabBar、液态玻璃、卡片、开关等
│   └── theme/                   # 颜色/主题/字体（含深色模式）
└── AndroidManifest.xml          # 权限：VIBRATE、HIGH_SAMPLING_RATE_SENSORS
```
